# Growtopia Auto Surgery Script

An automated surgery script for Growtopia designed to perform surgeries efficiently and flawlessly. This script reads the patient's condition and automatically applies the correct surgical tools, saving you time and preventing mistakes during mass surgeries.

## Features

- **Smart Tool Selection:** Automatically detects the patient's pulse, temperature, and status to use the exact required tool (Sponge, Scalpel, Stitches, Antibiotics, etc.).
- **Fast & Optimized:** Minimal delay between actions for fast surgery completion.
- **Fail-safe Mechanism:** Prevents using the wrong tool that could kill the patient or waste expensive items.
- **Auto Malpractice Avoidance:** Stops or adjusts safely if the patient's condition becomes critical.

## Requirements

- A Lua Executor compatible with Growtopia.
- Sufficient surgery tools in your inventory (Sponge, Scalpel, Stitches, Anesthetic, Antibiotics, Antiseptic, Defibrillator, Pins, Clamp, Ultrasound).
- A patient (or Surgery Bob) placed on a surgery bed.

## How to Use

1. Stand in front of the patient or Surgery Bob.
2. Ensure you have all the necessary surgery tools in your backpack.
3. Execute the script using your Lua executor.
4. Start the surgery, and the script will automatically take over the operation until it finishes.
5. (For GENTAHAX v5.59 - Patch b1.0, do not open the chat to avoid a force close caused by an FPS drop.)
